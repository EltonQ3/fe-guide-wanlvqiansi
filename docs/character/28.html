物品

カガヤキウオ ×1

可探索南部ブロンテス湖取得。カガヤキウオ是稀有采集物，可能需要多次探索，不能保证一次取得。准备招募时先保留1条，再用于其他交换或消耗；支援与名声仍按本线条件。凯伊线尚未到湖边时，可按下方矿山通路前往。

适用：凯伊线 / 迪托利希线 / 赛奥朵拉线 / 蕾达线

凯伊线
先到帝都西南「ワルハラ鉱山」，穿过矿山，从大房间左后方通道的「未達出口」回到世界地图，开放通往「ブロンテス湖」的道路。到湖边探索收集カガヤキウオ×1；稀有鱼可能需要多次探索，不把一次未出货当作走错地点。保留1条回帝都，在已满足3S／6R后从妮涅的「スカウト」交付入队。出发前检查当前队伍状态并预留探索、往返的行动时间。

怎么养，怎么转职

编辑培养建议

抗魔前排／枪系输出

前期
先完成鱼类交付再入队。培养枪术，利用对魔法兵种的个人能力安排对位。
中期
ガーディアン方向可兼顾前排职责；仍要核算实际魔法伤害。
后期目标
候选：ホーリーランサー。
考试与解锁
枪术 A；按阶段开放进行考试。
取舍与限制
对魔法的命中／回避优势并非免伤。Lv.35 周边支援效果不要提前计入。

这些是阶段性培养方向，并非必须逐级转职的固定链。适用难度及版本未做独立实测；优先满足当前队伍缺口。
