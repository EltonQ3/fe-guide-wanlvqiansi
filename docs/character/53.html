怎么养，怎么转职

编辑培养建议

后排法术／机动攻疗

前期
入队后按队伍缺口选主轴：需要伤害先黑魔术，需要回复先白魔术。她擅长黑白魔术与马术，不必为兼修物理武器拆散训练。个人技能只在魔法回复队友时按幸运百分比省次数，不能把概率效果当作稳定免耗。
中期
省训练的步兵方案可用萨满巫师 → 先知承担输出，或牧师 → 主教承担回复。牧师精通的信仰心提供幸运+3，本来就走回复路线时可顺路取得。需要机动攻疗且已解锁游唱诗人，再追加马术训练；未解锁时维持现有法师。
后期目标
第三部可考虑ヴァルキュリウム，兼顾黑白魔术与机动；另须完成茱拉的委托。若以治疗续航为主，贤者延续白魔术投入，但不能使用黑魔术，不能照搬原来的黑魔法输出职责。
考试与解锁
先知按黑魔术B备考；游唱诗人按马术D、黑／白魔术B选择项准备，未解锁时可通过凯伊的贝特朗名声10稽古或蕾达的新商品兴行4开放。贤者按白魔术A、ヴァルキュリウム按马术D与黑／白魔术A选择项准备。票证、开放进度与通过率看当前考试界面。
取舍与限制
HP、守备与速度并非长项，战斗预览确认伤害与追击后再出手，回复后也要避开敌人物理攻击范围。蕾达招募门槛较低，其他线不要照搬投入优先级；已有能胜任职责的法师时，先按缺口决定是否另花3000G和训练资源。

这些是阶段性培养方向，并非必须逐级转职的固定链。适用难度及版本未做独立实测；优先满足当前队伍缺口。
