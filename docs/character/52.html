任务

完成「鲁鲁迪娅的请求」

接下「ルルディヤーの頼み」后，到帝都东南「カリアネイラの港」听取水手消息，再回帝都报告。凯伊线可参考下方港口会话与马车行程。

适用：凯伊线 / 迪托利希线 / 赛奥朵拉线 / 蕾达线

凯伊线
满足3S／9R后，从「スカウト」接下「ルルディヤーの頼み」。到帝都东南「カリアネイラの港」，打开「会話」并选择「船乗り」听取消息；随后回帝都，从鲁鲁迪娅的「スカウト」对话报告，确认她正式入队。若「フェロニア駅」已经开放，可用「東アマルテア駅→フェロニア駅」的乘合马车缩短往返；未开放时需按当前通路安排更多回合。出发前检查本次任务期限，并预留回报时间。
