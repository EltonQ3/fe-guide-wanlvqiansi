怎么养，怎么转职

编辑培养建议

回避型剑手 · 飞行方向按需追加

前期
个人技能在 HP 至少一半时提供回避 +10；学会「绝好调+」后，满血还会获得攻击力 +3、回避 +10。先保证治疗跟得上，再让她接敌；这些加成并不等于必定闪避。
中期
省训练的方案是专攻剑术，沿剑客 → 侍道推进。若队伍缺机动、且有余力补飞行术，再准备飞行方向；不必为了过渡同时训练剑、枪、飞行三项。
后期目标
第三部可继续走刀剑将领，保留剑系投入；需要越过地形支援时，可改以圣天翼兵为目标。前者训练集中，后者多一项飞行训练与弓特效风险，按队伍缺口选一种即可。
考试与解锁
剑系按剑术 C → B → A 准备；圣天翼兵则以剑术或枪术 A、飞行术 C 为备考方向。仍须开放对应考试并满足票证、特殊解锁与通过率要求；没有开放时继续使用当前兵种。
取舍与限制
她的 HP、守备与力量成长不突出，避免一次承受多名敌人攻击。飞行后尤其要看敌方弓的特效与战斗预测。已有成型剑手、又不缺机动时，继续养现有主力比重新投入更省资源。

这些是阶段性培养方向，并非必须逐级转职的固定链。适用难度及版本未做独立实测；优先满足当前队伍缺口。
