## 1.2 难度与模式

| 项目 | 推荐 | 说明 |
|---|---|---|
| 难度 | **普通**（新手）／**困难**（老手） | 困难可在「方尖塔大厅」随时下调；但**一旦下调，本章进行中无法回调** |
| 模式 | **轻松**（新手）／**经典**（硬核） | 经典模式下伙伴阵亡不复活；但**当章内可用「章重来」回到开头**挽回 |
| 存档 | **注意单存档机制** | 本作只有一个存档位：手动存档会覆盖自动存档，新自动存档也会覆盖手动存档 |

> **普通与困难的核心差异，不只是敌人强度。** 关键在**「天刻的白沙」**——它是**回溯时间**的消耗品，同时也是**战斗中启用神之加护**的消耗品。**普通难度下芙托娜的回溯免费（0 沙），困难难度每次回溯要花 5 沙。** 这意味着困难难度下，**回溯与加护在争夺同一份资源**。

## 1.3 四主角路线推荐顺序（三语站共识）

中文站与日文站给出的顺序完全一致——**凯伊 → 赛奥朵拉 → 迪托利希 → 蕾达**（由简至难）。

| 顺序 | 主角 | 推荐理由 | 适合人群 |
|---|---|---|---|
| **1** | **凯伊 Cai** | 固有系统类似支线任务，机制简单易懂；名声最易积攒，招募队友轻松；自带范围攻击，战斗容错高；地图范围最小，便于熟悉探索 | 完全新手 / 系列新人 |
| **2** | **赛奥朵拉 Theodora** | 独有「军团兵」可下达计略指令（范围攻击、异常回复），攻辅兼备；但需要较多地图探索与时间管理 | 想稳妥体验的玩家 |
| 3 | **迪托利希 Dietrich** | 名声提升较难，要求严格日程安排；专属任务是狩猎强敌，战斗经验与经验值获取量极大 | 战斗爱好者 / 想刷战斗次数 |
| 4 | **蕾达 Leda** | 名声最难提升；侧重复仇主题与支援（Buff）打法；**唯一能解锁「舞者」职业的路线**，且解锁后其他路线也可用 | 二周目 / 支援流玩家 |

> **英文站补充**：Polygon 与 GameSpot 均建议**新手从凯伊开始**，称其为「Starter Option」；Theodora 适合老手（剧情专有名词多、政治线复杂）；Leda 适合支援流玩家。GameSpot 特别提示：**在方尖塔大厅如果转身离开房间，会直接触发最终决战**——此时无法招募四主角及部分重要角色，等于「硬核模式」。

## 1.4 时间与「自由行动」——最容易被误解的机制

> **核心结论：时钟本身毫无意义，只有「回合数」重要。**

- 每天分为 4 个 6 小时时段（0:00–5:59 / 6:00–11:59 / 12:00–17:59 / 18:00–23:59），**每个时段 = 1 回合**，4 回合 = 1 天。
- 时间**不会实时流逝**——只要你没有执行消耗回合的行动，时钟会自动停住（会停在 5:59 / 11:59 / 17:59 / 23:59）。所以不用担心「浪费时间」。
- 放置时时间也会走，**长时间挂机请先打开菜单**。

## 1.5 每周固定行动总表（不消耗回合，但每周限一次）

**三语站一致建议：统一在「星期日」做，因为周日效果好。**

| 行动 | 效果 | 周日加成 | 是否消耗回合 |
|---|---|---|---|
| **用餐（宿屋）** | 提升同席 3 人的支援值；恢复 HP、魔法次数、干劲 | **花费减半** | 否 |
| **训练（斗技场）** | 提升技能 EXP（**最有价值的周常**） | — | 否 |
| **侍奉（神殿）** | 提升加护等级与支援值；解锁神之加护 | **贡献度获得量增加** | 否 |
| **喂食白鸦** | 提升任意角色与主角伊修玛尔的支援（**第三部才生效**） | 仅周日 | 否 |
| **送礼** | 提升想挖角角色的支援值；**首次赠送解锁用餐资格** | — | 否 |
| **马厩喂食** | 仅**凯伊篇**可用 | — | 否 |
| **宿屋住宿** | 恢复 | — | **是** |

> **实践建议**：自由行动期间外出探索鞑古扎大陆，但**每周至少回一次鞑古席翁**完成周常，然后再出发。

## 1.6 「先见之助言」——自由行动的决策罗盘

从「冒险手帐」可查看**先见之助言**，他会直接告诉下一场主战所需的准备：

| 项目 | 对应准备 |
|---|---|
| 推荐 Lv. | 去遭遇战或地牢练级 |
| 推荐武器 Rank | 武器店购买 / 万达鲁商会兑换 |
| 推荐兵种 | 资格考试转职 / 挖角新同伴 |
| 推荐道具 | 购买 |

> 自由行动不知道做什么时，打开「冒险の手引き」执行**推荐度 3** 的内容。宿屋的「おまかせ稼ぎ」（自动活动）主要用于**调整时间**——比如快接近周日时用它快进。

## 1.7 名声（Renown）与名声等级

- 名声达到一定数值会提升**名声 Lv.**，解锁各类要素与新同伴的挖角资格。
- **主要来源：完成支线任务（Subquest）**。自由行动开放后，**把所有可接的支线全部接下**，并在期限内完成并报告。
- 其他来源：完成主线、外传、部分事件；与神「谒见（拝谒）」时也可提升。
- **注意**：迪托利希篇与蕾达篇名声提升明显更难，需要更严格的日程规划。

# 第二篇 · 核心系统机制

## 2.1 支援等级系统——本作最值得优先投入的长期投资

> **关键机制：支援等级是「全局数值」（Global Value）。**

在任意一条路线上提升两名角色之间的支援，该等级会**保留并同步反映到其他所有路线**，且**永远不会下降**——即使重开章节也不会掉。这意味着：

- 你在凯伊篇刷的蕾达 × 其他角色的支援，会让蕾达篇的招募变得**更容易**。
- **跨路线重复收益**：这是本作性价比最高的长期投资。

**提升支援的四种方式**：

| 方式 | 说明 |
|---|---|
| **邀请用餐** | 宿屋内选择用餐，可同时提升同席 3 人支援；同时恢复 HP 与魔法次数，**务必每次都用** |
| **赠送礼物** | 只有送**对方喜欢的物品**才会提升支援值；主要用于尚未入队、想挖角的角色 |
| **联手攻击（连携）** | 地牢等战斗中发动联手攻击可提升参战同伴支援值 |
| **剧院观演** | 剧院开放后，可观演（可含 Guest）或参演（仅限已招募角色） |

**支援等级的效果**：战斗中相邻的同伴会获得能力加成；高等级可解锁特殊事件（可在宿屋「支援会话」中回看）。

**重要提醒**：
- **A 级是上限，本作没有 S 级支援、没有结婚系统**；恋爱元素只存在于角色剧本写作中，不是系统机制。
- **不要过度依赖送礼**——主要手段应是宿屋「用餐」：可每周多次、可同时提升多组支援、还能提升**非主角之间**的支援，甚至可邀请不可招募的角色（部分角色有支援对话）。

## 2.2 【重点技巧】支援等级速刷法（零成本）

利用「支援全局化 + 不下降 + 章节重开」三个特性叠加：

1. 重开一个**已通关**的章节；
2. 在宿屋为想要提升支援的角色组合**举办多轮用餐**；
3. 用宿屋的「自动活动」推进到下一周，继续用餐；
4. 重复直到该章主战前的回合耗尽；
5. 基地菜单 → 系统 → **重开章节（Restart Chapter）**，回到步骤 1。

**要点**：
- 过程中**不消耗任何金钱和道具**（只是反复读档），理论上甚至不需要中途存档，只要最后存一次。
- 建议**选择较长的章节**（RPG Site 作者用蕾达篇第 9 章示范），重开前能办更多次用餐。
- 开始前最好已在上一章给所有角色送过礼，否则每次重置都要重新送礼解锁用餐功能。
- 注意部分章节中特定角色群（凯伊、迪托利希、赛奥朵拉、塔利穆恩、阿纳托莉娅的队伍）会不在鞑古席翁，需换到他们在场的章节。

## 2.3 战斗系统与计算式

**基础规则**：
- **武器克制倍率**：无特攻 = 等倍；有效 = 武器威力 **2 倍**；特攻 = 武器威力 **3 倍**。
- **暴击**：伤害 **3 倍**。
- **追击条件**：攻速差 **≥ 4** 即可追击（普攻两次）。
- 所有小数**向下取整**。

**核心公式**：

| 项目 | 公式 |
|---|---|
| 物理攻击 | 力 + 武器威力×特效补正 + 战技补正 + 技能 + 其他补正 |
| 魔法攻击 | 魔力 + 魔法威力 + 战技补正 + 技能 + 其他补正 |
| 物理防御 | 守备 + 装备守备 + 地形 + 其他补正 |
| 魔法防御 | 魔防 + 装备魔防 + 地形 + 其他补正 |
| 必杀 | (技 + 幸运) ÷ 2 + 武器/魔法必杀 + 技能 + 其他补正 |
| 命中 | 技 + 武器命中 + 战技补正 + 装备命中 + 技能 + 神の加護 + 其他 |
| **攻速** | 速度 −（装备总重量 − 体格），最低为 0 |
| 回避 | 攻速 + 技能 + 地形 + 神の加護 + 其他 |
| 必杀回避 | 幸运 + 技能 + 神の加護 + 其他 |
| 物理伤害 | (物理攻击 − 物理防御) × 必杀补正 × 技能 × 神の加護 |
| **攻击命中率** | 命中 − 回避 |
| **必杀发生率** | 必杀 − 必杀回避 |

> **实战要点**：英文站特别强调**「本作基本不是回避环境」**，因此**坦克型角色非常吃香**。这与前作以回避为核心的 Meta 有明显差异。

**关键战斗技巧**：
- 按 **ZL** 可显示全部敌人的攻击范围（红色高亮），用于卡位与保护脆皮。
- 武器有**有效（×2）**与**有效+（×3）**两级：枪对骑兵 ×2、弓对飞行 ×3。
- **攻击速度（AS）= 速度 − 装备重量影响**，比对手高 **4 以上**才能追击——布阵前务必核对 AS、Prt、Rsl。
- **战技（Combat Art）**消耗武器耐久，可提升威力/命中/必杀；**Blaze Arts 消耗 HP**，使用会填充「Blaze Gauge」，**充满后降低该单位最大 HP 并清除所有加成**。

## 2.4 Blaze Arts（主角专属大招）

四位主角各有专属 Blaze Arts，**消耗 HP**，是改变战局的关键，但**使用时机至关重要**。

> **建议**：开启前先确认敌方攻击范围；准备好治疗；尽量把主角移出危险地带；或选在能一举清掉「有能力反击的敌人」时使用。**只有当 HP 代价不会引发新的危机时，Blaze Art 才是最有价值的。**

| 主角 | Blaze Art 特性 | 战术定位 |
|---|---|---|
| **凯伊 Cai** | **范围攻击**（本作罕见的 AOE） | 高容错主力，机动力极强 |
| **迪托利希 Dietrich** | **强调位移与站位**，可快速贴脸；影渡（可无视障碍瞬移） | 近战物理爆发、必杀流 |
| **赛奥朵拉 Theodora** | **远程巨岩投掷**，攻击范围全游戏最大 | 顶级肉盾 + 远程支援 |
| **蕾达 Leda** | **范围 Buff 歌曲**，可同时强化周边多名同伴 | 支援核心，需居中站位 |
| **伊修玛尔（救世主）** | **「破邪闪击」大范围攻击**，极为强力 | 均衡型，起始等级高 |

**蕾达专项建议**：她的歌曲「站位与选曲同等重要」。使用前先查看技能范围，把想强化的单位移入范围，尽量一次覆盖多名能立刻输出的角色。一个实用套路是：**把同伴放进敌方攻击范围，再用她提升守备与魔防的技能**，从而轻松反杀。

# 第三篇 · 加护（侍奉）心得

> **名词澄清**：「侍奉」是每周限一次的行动，解锁的是**神之加护**。请勿与「救世祝福」混淆——后者是用「伟业碎片」在因果神殿兑换的另一套系统。

## 3.1 加护系统基本规则

| 规则 | 内容 |
|---|---|
| **神殿数量** | 鞑古席翁「神殿街」共有 **7 座神殿**，对应 7 位神 |
| **获取方式** | **6 位神通过侍奉解锁**；**芙托娜通过剧情解锁，不可侍奉** |
| **侍奉成本** | 每次带**最多 2 名角色，每人消耗 1 点干劲** |
| **每周限一次** | 侍奉是**每周一次**的行动，不消耗回合 |
| **等级范围** | 大多数神为 **1 级 → 3 级**，填满计量条即升级 |
| **战斗携带上限** | 战斗前**最多装备 4 个加护** |
| **启用成本** | 战斗中启用需消耗**天刻的白沙** |

> **关键机制：加护不是免费的。** 启用加护消耗**天刻的白沙**——**和困难难度回溯时间用的是同一种资源**。所以在困难难度下，**加护与回溯在争夺同一份资源**，别把沙浪费在低价值加护上。

# 第四篇 · 送礼心得

## 4.1 一句话结论

> **送礼的核心作用是「解锁用餐资格」和「补足支援差」，不是主力刷支援手段。**
>
> 送对礼物（对方喜欢的）获得的支援量 ≈ 请对方吃一顿他喜欢的饭。但由于**赠礼每周每人只能一次**，而用餐**每周可办 3 次 × 3 人**，因此英文站明确建议：**不要把送礼当主要手段**，主力应是宿屋用餐。

## 4.2 送礼的机制规则

| 规则 | 内容 |
|---|---|
| **每周限一次** | 赠礼是**每周行动**，同一角色一周只能送一件 |
| **每周日重置** | 每周从**星期日**开始 |
| **地点限制** | 只有在角色**人在鞑古席翁（Dagsion）**时才能送。可从地图菜单的**角色页签**查看谁在场、当前支援等级，并**直接快速传送**过去 |
| **首次送礼 = 解锁用餐** | **送出第一件礼物后，才能邀请该角色参加宿屋用餐**——这是送礼最关键的机制作用 |
| **招募前置** | 每个角色**至少需送出 1 件礼物**，才可能成为可招募对象 |

### 支援增加量分级

| 反应 | 支援增幅 | 说明 |
|---|---|---|
| 不喜欢 | **无支援增加** | — |
| 有点喜欢 | 小幅增加 | — |
| 喜欢 | 中等增加 | — |
| **非常喜欢** | **大幅增加** | 约等于请吃一顿他喜欢的饭 |
| **非常喜欢 + 双黄箭头** | **双倍点数** | 仅限「最爱物品」 |

### 礼物稀有度

| 稀有度 | 图标特征 |
|---|---|
| **普通** | 深蓝绿色图标 |
| **罕见** | 颜色更浅，**右下角有符号** |
| **稀有** | 更浅，**左上角有小闪光** |

> **注意**：部分角色**只接受罕见或稀有的物品**，无论类别（例：卡塔妮雅偏好「任意稀有物品」）。

### 礼物分类（共 18 类）与获取渠道

**分类**：时尚 · 美容 · 花卉 · 烹饪 · 发酵饮料 · 一般饮料 · 咖啡 · 训练用品 · 武器 · 军用品 · 马匹用品 · 书籍 · 棋盘游戏 · 蔬菜 · 手工艺 · 钓鱼 · 弓术

| **低城区酒馆** | 可购买咖啡、Cervi 等饮料 |

## 4.3 送礼核心技巧

### 技巧 1：用「物品描述」反查角色 —— 本作的关键机制

> 本作对「谁喜欢什么」**刻意保持模糊**。礼物本身的描述会写明「主要为喜爱书籍者所享受」之类，**玩家需要自己反查匹配的角色**。

**举例**：一件描述为「喜爱书籍/阅读者」的礼物，可选对象包括——
**奥罗拉、班迪兹、贝特朗、菲亚娜、鲁鲁迪娅、努蒂奴、奥尔赫尔、西洛可、蒂亚拉、乌修拉**

**辅助判断线索**：
- **成年人**普遍喜欢发酵饮料，**儿童不喜欢**
- 从**外观**可推测——例如看起来讲究时尚的角色会喜欢时尚类
- 查看角色信息会**直接透露部分喜好**

### 技巧 2：别死磕「最爱」，退而求其次完全可以

> 如果某一周甚至整章都没有对方「非常喜欢」的东西，**给个他「勉强能接受」的也完全没问题**——第一部结束前有充足时间刷支援，不必焦虑。

### 技巧 3：餐桌才是主力，送礼用来补齐

1. **每周 3 顿用餐**（宿屋上限 3 次 × 3 人）
2. 如果目标是招募：**每顿饭都必须包含「你的主角 + 两个想招募的对象」**
3. **先送一次礼**给 Guest，才能邀请他入席
4. **如果某位 Guest 不喜欢当天的菜色，就换成另一位喜欢该菜色的招募目标**
5. **三人越都爱吃，支援涨得越多**

### 技巧 4：剧院（Theatre）—— 被忽略的第三渠道

- **参演**：只能从**已招募**的角色中选择
- **观演**：可包含**主角 + 一位 Guest**
- **只要两人真的喜欢该场演出**，就能获得**可观的支援提升**

### 技巧 5：战斗与连携也能刷

| 方式 | 说明 |
|---|---|
| **相邻战斗** | 让想提升支援的两名角色**相邻站位**并攻击敌人结束回合，每次获得小额支援加成；**每场战斗的每个回合都能刷** |
| **连携攻击（Link Attack）** | 地牢战等场景发动连携攻击，同样提升两人支援 |

### 技巧 6：注意角色在场情况

某些章节中特定角色群**不在鞑古席翁**——凯伊、迪托利希、赛奥朵拉、塔利穆恩、阿纳托莉娅的队伍会缺席。想给这些人送礼或办餐会，**需换到他们在场的章节**。

# 第五篇 · 角色培养

## 5.1 资源分配原则：「少而精优于多而弱」

- **不要平均培养所有人**：每条路线的角色数量都超过你能同步培养的量。先确立**5–6 名核心主力**用于主战，其余训练机会留给专精角色与未来招募的新人。
- 核心队伍应覆盖明确分工：**耐打的前排、高机动输出、远程火力、可靠的治疗/支援**。

## 5.2 转职与资格考试

- 通过**资格考试**转职（系列传统），需满足技能 Rank 要求 + 消耗「许可证（ライセンス）」。
- **许可证别只盯着鞑古席翁的商人**——初期物资极度吃紧。**其他聚落也售卖许可证**，在世界地图上**按 ZL 悬停查看库存**后再前往。
- 确认「先见之助言」中的**推荐兵种**，据此决定是转职还是挖角新人。

## 5.3 挖角招募：三项要素 + 附加条件

| 要素 | 说明 |
|---|---|
| **支援等级（nS）** | 与你的主角之间的支援等级。最佳提升方式：送礼 + 邀请用餐（+ 剧院观演） |
| **名声等级（nR）** | 全局数值，完成主线、支线、外传等提升；也可通过与神「谒见」提升 |
| **附加条件** | 少量金钱、回答问题、特定道具，或完成 1 个甚至多个支线 |

## 5.4 跨路线全局进度：救世祝福与伟业录

## 5.5 【高价值技巧】重复招募角色要「差异化培养」

- **同一个角色可以在多条 Part 1 路线上入队。**
- 如果你打算在 Part 3 使用该角色，**不要让每个版本都练成同一套配置**——一个版本练骑马系、另一个走不同武器线，或在不同路线收集不同精通能力。
- Part 3 的 **Merge Causality（合并因果）** 系统会把各版本中**有用的职业、能力、战技、技能等级和更高属性**汇总到最终版本上。

| **蒂亚拉** | 白魔法技能 C 即习得「リブロー（远隔治疗）」；数值平凡但作治疗足够 |
| **艾丝梅拉达** | HP、力、守备成长优秀；速度也能成长且有**重量减轻**，不易被追击；守备→重甲，速度→バーディンガー / ドラグーン |
| **古扎岚** | 成长全面，近战物理合格；**个人技能「気分屋」极强且可随升级强化**；**蕾达篇建议早期挖角** |
| **歌利亚** | HP、力、守备成长优秀的坦克；可视作**奥尔赫尔的下位互换**，但**奥尔赫尔在「过去篇」无法挖角**，故实质上是该篇最优坦克 |

### 真正该投资的三件事（而非追逐排名）

1. **个人技能（Personal Ability）**——**固定且不可转移**，是唯一不随存档变化的要素。例：提升周边同伴回避、可在战场直接使用仓库、减轻武器重量、**有概率以 1 HP 存活致命一击**。
2. **技能等级（Skill Level）**——驱动战技与可装备能力，**在斗技场投入的时间会复利**，不论你练的是谁。
3. **支援等级**——**永不下降、跨路线继承**，是全游戏最安全的长期投资。

# 第六篇 · 路线切换与错过要素

## 6.1 路线切换策略：一个重要的分歧点

| 来源 | 建议 | 理由 |
|---|---|---|
| **RPG Site** | **一次通关一条 Part 1 路线**再开下一条 | 只有**完整通关**一条 Part 1 后才可继承进度；中途停下则无法继承。继承内容包括：**世界地图探索数据**（不必重做探索）、**通用支线自动完成**（不必做 4 遍） |
| **TheGamer** | 可用**路线切换**避免重复刷（也可一条条通） | 在四条故事间来回可让各军保持相近进度，并享用新解锁的全局加成 |

**共同点**：无论哪种方式，**后续路线都应越来越快**，不必把首条路线的流程原样重复四遍。

**全局继承内容**：支援等级、加护等级、伟业录、救世祝福 —— 全部**跨路线全局有效**。

## 6.2 不可挽回的要素

| 项目 | 说明 |
|---|---|
| **救世祝福** | 一经取得**无法更改**，选择需谨慎 |
| **侍奉加护等级** | 本身全局继承、不会丢失；但**每周只能侍奉一次**，冲哪条线是长期决策 |
| **升级时的属性成长** | 数值随机，成长趋势受个人成长率与兵种影响；可消耗「天刻的白沙」回溯战斗**有限度地**挑选结果 |
| **第 2 部无法挖角** | Part 1 通关进入 Part 2 后，**几乎全是战斗部分**，挖角等 Part 1 能做的事**全部消失**——务必在 Part 1 结束前把招募搞定 |
| **难度只能降不能升** | 游戏中可下调难度，但**下调后本章无法调回** |

## 6.3 可通过「章重来」挽回

基地菜单 → **系统 → 章のやり直し**（回到该章开头）：

- **阵亡的同伴**（经典模式）
- **已过期的任务**（注意：若该章开头时尚未触发该任务，重来后需从接取开始）
- **与同伴对话的选项**（部分选项可提升支援值，可借此重选）

## 6.4 可通过「再降临」挽回

保留剧情进度，重置角色与游戏模式（需先在方尖塔存档，且需重玩序章起见的部分）：

- **主角姓名与外观**
- **难度与模式**

# 附录 · 每周日常速查卡

**周日（周日常行动日）标准流程：**

1. 回鞑古席翁（**周日用餐花费减半、侍奉贡献度增加**）
2. 打开地图 → 角色页签，**确认本周有谁在场**
3. 给**尚未送过礼的招募目标各送 1 件**（解锁用餐资格是首要目的）
4. **办 3 顿饭**，每顿都安排「主角 + 2 名招募目标」，尽量选三人都爱吃的菜色
5. **侍奉**——按第 3.3 节优先级选神殿；若本周某天是目标神专属日，改那天去
6. 顺路去**剧院**看一场演出（主角 + 1 名 Guest）
7. **训练（斗技场）**——提升技能 EXP，为资格考试铺路
8. **喂白鸦**——提升与伊修玛尔的支援
9. 地图上**神殿图标变金色**时，参加公开谒见拿约 50 点名望（不耗回合）

**优先级判断：**

> **① 每周 3 顿精准用餐 ＞ ② 侍奉（按 T1→T5 排序） ＞ ③ 每周 1 次送礼（解锁+补差） ＞ ④ 剧院观演 ＞ ⑤ 战斗相邻刷支援**

## 注意事项

- **真主角默认名的译法分歧**：简体中文媒体存在「伊修玛尔」（默认名，官方设定）与「埃什梅尔」（英文 Eshmel 音译）两种写法。**以「伊修玛尔」为准**。
- **魔神名**：任天堂香港 eShop 作「霸羅爾」，简体正文统一为**霸罗尔**。部分简中媒体写作「巴罗尔」，仅作旧译保留，不再用于正文。
- **部分角色在中文站有多个暂译**（如蒂亚拉/媞雅拉、杰斯特/杰斯塔），对照表的 `alias_zhs` 字段保留了别名以便检索。
- 随官方陆续公布角色介绍，标记为「⚠️ 社群」的条目应逐步升级为「✅ 官方」。
- **同一角色只保留一个简体写法**。无官方译名时，以招募表所用社群译名为准；送礼表里的另一套音译已并入，旧译见译名表「别名」。
- **「白鸟」与「白鸦」**：任天堂用语「白鳥」的简体是**白鸟**，指据点内切换主角的设施。正文「喂食白鸦」尚未核对为同一对象，因此没有改名。
