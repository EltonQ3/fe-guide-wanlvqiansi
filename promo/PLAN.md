# 宣传片企划与制作说明

本文件写给接手宣传片的人或 agent。新工作阶段开始时先读本文件，再读 `timeline.json`。

## 1. 站主已确定的事

- **主平台：** B 站，16:9，1920×1080，30fps。
- **先定长版（60 秒）的视觉与方向，再做短版（15 秒）。** 短版目前仍是第一版（`audio/synth.py` + `src/Video.tsx`），待长版定稿后按新风格重做。
- **长版的核心：** 游戏的主题是回到过去、万缕丝线交织、改写命运的宏大史诗。先用视听唤起对游戏的渴望，再展示网站易用、优雅、美观，最后回到「四线汇一、逆转宿命」首尾呼应。
- **语言克制：** 不讲玩家痛点，不用焦虑的语言（例如「一条线要打 40 小时」）。
- **网站画面：** 不要长时间全屏展示网页（视频里看不清），要灵活运镜、多用特写。
- **不拘泥于网站本身：** 用 three.js、canvas 等工具做出绚丽恢宏的视觉。
- **配音：** 不是必需。长版目前不配音，靠音乐与画面文字；日语配音工具（`audio/vo.py`）保留，见第 6 节。
- **片尾网址：** `fe-guide.pages.dev`。
- **项目位置：** 本仓库 `promo/`，与网站构建无关，网站仍不需要 npm。

## 2. 结构（72 BPM：每拍 25 帧，每小节 100 帧，全片 18 小节）

| 帧 | 场景 | 画面 | 音乐 |
|---|---|---|---|
| 0–200 | one | 一根金线（画成振动的弦），拨响后唱出命运动机；175 帧在最后一个音上断裂，火花四溅。字：命运之线，于此断裂。 | 竖琴单音，再奏动机 A–D–E–F（D 小调） |
| 200–300 | rewind | 时间倒流：断线倒着飞回，命运之环逆转；300 帧两端重新接上，一道闪光。字：若能回到那一天—— | 开头的竖琴**倒放**，弦乐渐强 |
| 300–400 | myriad | three.js：线化作万缕，站内全部同伴立绘悬在丝线里，镜头穿过隧道和命运之环。字：千丝万缕，重新交织。 | 小提琴接过动机，脉动开始，推向 400 帧重击 |
| 400–800 | hero-* | 每小节一位主角：立绘像织布一样一条条织入，各有天气（风、剑光、灯火、蔷薇花瓣），名字与标语 | 各有主题乐器，见第 3 节 |
| 800–1400 | book / read / planner / calendar / night / gather | 网站：真实截图上的运镜特写（首页标题 → 路线横幅与手册正文 → 招募规划按拍标记、金线连到清单 → 外传日历「今天」线 → 昼夜切换与手机 → 八个半拍快切，全部被拉成丝线） | F 大调，竖琴与跳弓，动机转为大调；1300 起渐强 |
| 1400–1600 | converge | three.js：四色丝线螺旋汇聚，站内全部同伴卡（约 190 张）被卷入漩涡；第 15 小节起（1500 帧）卡片按十六分音符一圈一圈锁定，结晶成一个巨大的「命运之轮」，四位主角居中成十字，金线辐条连向中心；轮子逆转、在终止式上停住、再正转，镜头穿过轮心冲进光里。字：于万缕命运间，走出你的胜局。（底下有一条暗色字幕带） | 全奏：四个主题同时出现，Bb–C–D 落到 **D 大调** |
| 1600–1800 | end | 一根稳定的暖金线、站名「万缕千丝 · 战术手帖」、网址、非官方与版权说明；竖琴以大调重奏动机，线随每个音颤动 | 大调尾声 |

精确的帧、同步点（断裂、接回、重击、标记、钟声、昼夜切换）和画面文字都在 `timeline.json`（`long.sync`、`long.copy`），改时间或文案只改那里。

## 3. 配乐（`audio/score.py`）

- **素材：** VSCO 2 Community Edition 管弦乐采样（Versilian Studios，**CC0**，可商用、无需署名）。`audio/fetch_samples.sh` 只取用到的乐器，约 1.9 GB，放在 `samples/`，不进 git。
- **采样器：** `audio/orchestra.py`，用最近的采样音高重采样到目标音；力度选层，轮替采样；连奏音跳过起音并交叉淡入。多数 VSCO 文件名比实际低一个八度（已用音高检测核对；竖琴与独奏小提琴除外），脚本已处理。
- **四位主角的主题乐器：** 四个主题都由同一个动机（上行四度再级进）变化而来，所以最后能叠在一起。
  - 凯伊：长笛。风一样的上行跑句。
  - 迪托利希：大提琴组。异乡剑客的低沉长线。
  - 赛奥朵拉：圆号。女王的附点号角；采样只到 C4，所以放在圆号温暖的中音区，上方加一支轻小号。
  - 蕾达：独奏小提琴。和声小调与增二度，蔷薇的复仇之歌。
- **调性叙事：** 全片 D 小调（宿命），最后 Bb–C–D 进行落在 D 大调，动机里的 F 变成 F♯，即「命运被改写」。
- **声音设计（合成）：** 断弦、风声、剑鸣、低频重击、倒放的镲与竖琴（时间倒流）、余烬噼啪。
- **混音：** 按声部分轨后加卷积大厅混响，轻度压缩，整体 -14 LUFS，峰值约 -1.4 dBFS。动态弧线约为：开头 -27、主角 -19、网站段 -23、全奏 -11（LUFS，逐小节）。`python3 audio/score.py --stems` 会打印各声部各段响度，供平衡参考。

## 4. 画面（`src/long/`）

- `ActOne.tsx`：振动的弦、断裂、倒流、命运之环。
- `Tunnel.tsx`：三维同伴隧道。
- `Heroes.tsx`：织入的立绘与四种天气。
- `Site.tsx`：网站运镜。
- `Converge.tsx`：三维编织、同伴漩涡与命运之轮，以及片尾。片尾网址紧接站名出现（约 54.5 秒），停留约 5 秒。
- **首尾要有变化：** 开头（10–13 秒）是「散落、穿过」的隧道；结尾是「汇聚、结晶、逆转」的命运之轮。改动时保持这种对比，不要让两段变成同一种画面。
- `kit.tsx`：共用部件（文字逐字显现、命运之环、火星、颗粒、闪光）。
- **网站运镜：**
  - 截图为 2 倍分辨率，相机以「版面尺寸」缩放，不用 transform 缩放，所以特写清晰。
  - 画面边缘用预先模糊的副本做景深（`scripts/blur.py`）。
  - 所有叠加（金线、「今天」线、昼夜切换）都按截图时记录的元素坐标对齐，不画假界面。
- **素材限制：**
  - 不使用游戏配乐和实机画面。网站上引用的游戏截图（Game8 等来源）不进片，所以「read」一段的第二个镜头用的是攻略手册的正文页。
  - 立绘只用站内的 400×533 版本，以卡片呈现。
  - 片尾写明「玩家整理 · 非官方网站」与版权归属。

## 5. 制作流程与命令

```sh
cd promo
npm install                         # Remotion 4、three.js
sh audio/fetch_samples.sh           # 管弦乐采样（一次即可）
node scripts/prepare.mjs            # 复制站内立绘、兵种图标与西文字体到 public/
python3 ../tools/build_site.py && (cd ../docs && python3 -m http.server 8766 --bind 127.0.0.1 &)
npm run capture                     # 2 倍截图与元素坐标，再生成景深用的模糊副本
npm run audio                       # 长版配乐（score.py）与短版（synth.py）
npm run preview                     # 长版 1440×810 预览：out/long-preview.mp4
npm run render                      # 1920×1080 正式版
```

**环境说明：**
- Remotion 自带的浏览器下载被网络策略挡住，`remotion.config.ts` 改用环境里的 Chromium，WebGL 用软件渲染（swangle）。
- Remotion 的缩放比例必须让宽高都是整数，所以预览用 0.75。
- `public/`、`out/`、`samples/`、`node_modules/` 都不进 git；都可用上面的命令重建。

## 6. 日语配音（暂停；Google Cloud TTS，不得产生费用）

- `timeline.json` 的 `long.vo` 目前为空，长版不配音。如果以后要加，在 `long.vo` 写入提示帧与台词，再用 `audio/vo.py`。
- **金钥：** 由站主在云端环境设置，二选一：
  - 环境变量 `GOOGLE_TTS_API_KEY`；
  - 主机为 `texttospeech.googleapis.com` 的 API 凭据。
  - 两者都只对新的工作阶段生效。不要把金钥写进仓库或聊天。
- **费用控制（已写进脚本）：** 每月硬上限 2 万字元；按文本缓存；用量记在 `audio/tts-usage.json`。
- 录好的台词用 `audio/import_vo.py` 导入并记录长度。混音时需要在 `score.py` 中加入人声并压低音乐（旧版 `synth.py` 的做法可参考 git 历史）。
- 发到 B 站时若含 AI 配音，勾选 AI 生成内容标识。
