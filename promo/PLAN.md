# 宣传片企划与制作说明

本文件写给接手宣传片的人或 agent。新工作阶段开始时先读本文件，再读 `timeline.json`。

## 1. 站主已确定的事

- **主平台：** B 站，16:9，1920×1080，30fps。
- **长版 60 秒：** 日语 AI 配音，画面烧录中文字幕。
- **短版 15 秒：** 不配音，靠音乐和音效抓人。
- **音乐与音效：** 全部由程序合成（`audio/synth.py`），版权干净，音画由同一份时间表驱动。
- **配音：** Google Cloud Text-to-Speech（日语）。**站主要求不得产生费用**：脚本有每月硬上限和缓存，见第 5 节。
- **片尾网址：** `fe-guide.pages.dev`。
- **项目位置：** 本仓库 `promo/`，与网站构建无关，网站仍不需要 npm。
- **语言克制：** 长版不讲玩家痛点，不用焦虑的语言（例如「一条线要打 40 小时」）。

## 2. 创意：一根线 → 万缕千丝 → 一条命运

游戏本身就是四条路线最终合为一条线、改变命运。整片围绕这个意象，分三幕：

1. **第一幕「万缕」（0–26.7 秒）：** 只用情绪与视听，唤起对游戏的兴趣与渴望。一根线被拨响，分出万缕；四色线引出四位主角，最后汇成一股。
2. **第二幕「手帖」（26.7–46.7 秒）：** 那一股线落到网站首页的命运丝线上；平静地展示网站易用、优雅、美观，让人想用。
3. **第三幕「织命」（46.7–60 秒）：** 界面化回丝线，四色编成一股，收在网站首页标语「于万缕命运间，走出你的胜局。」与站名，首尾呼应。

## 3. 时间表（72 BPM：每拍 25 帧，每小节 100 帧，全片 18 小节）

| 帧 | 场景 | 画面 | 日语旁白（中文字幕） |
|---|---|---|---|
| 0–100 | one | 黑场，一根金线划过并被拨响 | 一本の糸から、物語は始まる。（故事，从一根线开始。） |
| 100–300 | myriad | three.js：线在景深中展开成数百根，镜头穿过；末段转为四色线 | 無数の運命が、交わり、すれ違う。（无数命运，交会，又错过。） |
| 300–700 | hero-* | 每小节一位：本线配色、本线丝线、立绘（站内 400×533，以卡片呈现，不放大满屏）、名字与本线标语 | リベイラに、風が吹く。／異郷に、剣が鳴る。／女王と、その国。／薔薇の、復讐の歌。（不另配字幕，画面标语即译文） |
| 700–800 | braid | 四线汇合，位置与网站首页丝线完全一致（无缝接到下一场） | 四つの道は、やがて一つの運命へ。（四条路，终将汇成同一个命运。） |
| 800–1000 | notebook | 首页截图出现在丝线下方，缩进浏览器窗口并缓缓下滚 | その旅路を、一冊の手帖に。（把这段旅程，收进一本手帖。） |
| 1000–1200 | planner | 招募规划：三人按拍被标记，金线从头像连到清单，清单逐步填满 | 誰と出会い、誰を迎えるか。（与谁相遇，迎谁同行。） |
| 1200–1300 | paralogues | 外传窗口一览，「今天」线滑过，拍点上轻响 | 見逃したくない、ひとときも。（每一段，都不想错过。） |
| 1300–1400 | night | 从主题按钮处圆形展开深色页面；手机版滑入 | 昼も夜も、静かに寄り添う。（无论昼夜，静静相伴。） |
| 1400–1600 | weave | 窗口收成一条线；四色丝线编成一股；首页标语浮现 | 幾万の糸の中から、あなただけの勝利を。（于万缕命运间，走出你的胜局。） |
| 1600–1800 | end | 一根金线、站名、网址、非官方与版权说明；开头那一拨在 1725 帧重现 | 无旁白 |

**短版（450 帧）：** 拨弦 → 万缕 → 四位主角各 50 帧 → 首页 → 招募规划 → 片尾。

精确的帧、旁白和音效事件都在 `timeline.json`，改时间请只改那里。

## 4. 声音设计（`audio/synth.py`）

- **主题动机：** 四个拨弦音 D、F♯、A、C♯，一位主角一个音。四线编在一起时四音同响；结尾落在高音 D，表示命运落定。开头那一拨在片尾重现。
- **音色：**
  - 拨弦用模态合成（衰减的泛音）；
  - 铺底用多层微失谐三角波并低通；
  - 低音用正弦；
  - 第二幕用柔和的类钢琴琶音、轻踢鼓和沙锤；
  - 铃声用 FM 合成；
  - 上升音、呼啸、点击声都是滤波噪声；
  - 最后加卷积混响。
- **段落动态：** 从静默升起 → 主角 → 汇合最强 → 网站段平静 → 夜晚降一层 → 回归 → 结尾最开阔。
- **响度：** 一次静态增益到约 -14 LUFS，加峰值限制在 -1.5 dB。不要用单遍 loudnorm，它会随时间调增益，把动态压平。
- **配音混音：** 有配音后，`synth.py` 自动把它放到各自的提示帧，并在人声下把音乐压低约 8 dB（0.15 秒渐变）。

## 5. 日语配音（Google Cloud TTS，不得产生费用）

1. 金钥放在云端环境变量 `GOOGLE_TTS_API_KEY`（站主已设置）。环境变量只对**新的工作阶段**生效；**不要**把金钥写进仓库或聊天。
2. 先试音，挑声线：

   ```sh
   python3 audio/vo.py voices
   python3 audio/vo.py audition <声线A> <声线B> <声线C> <声线D>
   ```

   - 男女各挑两个，把 `public/audio/vo/audition/*.wav` 发给站主选。
   - 方向：沉稳、温暖，类似动画 PV 的叙事口吻，语速偏慢。
3. 站主选定后生成全部旁白：

   ```sh
   python3 audio/vo.py render <声线> --rate 0.92
   ```

   脚本会报告每句长度。若某句超出到下一句的间隔，就调 `--rate`，或把该句的 `at` 往前挪（只改 `timeline.json`）。
4. 重新混音并渲染：`python3 audio/synth.py`，然后 `npm run render`。
5. **费用控制（已写进脚本）：**
   - 每月硬上限 `MONTH_CAP = 20000` 字元，超过就拒绝，不发请求。一次完整生成约 300 字元。Google 的免费额度以百万字元计，以官方价目页为准。
   - 按「文本＋声线＋参数」缓存，重跑不会重复计费。
   - 每次调用记录在 `audio/tts-usage.json`。
6. 发到 B 站时勾选 AI 生成内容标识（《人工智能生成合成内容标识办法》），片尾可加「日语配音：AI 合成」。

## 6. 制作流程与命令

```sh
cd promo
npm install                         # Remotion 4、three.js
node scripts/prepare.mjs            # 复制站内立绘与西文字体到 public/
(cd ../docs && python3 -m http.server 8766 --bind 127.0.0.1 &)   # 先 python3 tools/build_site.py
NODE_PATH=$(npm root -g) node scripts/capture.cjs     # 截取真实网站状态与元素坐标
python3 audio/synth.py              # 音乐与音效（有配音时一并混入）
npm run animatic                    # 960×540 动态分镜（日语以字卡占位）
npm run render                      # 1920×1080 正式版：out/long.mp4、out/short.mp4
```

**环境说明：**
- Remotion 自带的浏览器下载被网络策略挡住，`remotion.config.ts` 改用环境里的 Chromium，WebGL 用软件渲染（swangle）。
- 长版半分辨率渲染约十几分钟。
- `public/`、`out/`、`node_modules/` 都不进 git；素材可随时用上面的命令重建。

## 7. 画面与易读的约束

- **字幕：** 中文字幕在画面下方，衬线体，带阴影；任何画面上都要读得清楚。
- **立绘：**
  - 只以卡片呈现，慢推与染色，不拆图层、不 3D 化。
  - 站内立绘只有 400×533，不能放大成满屏。
  - 片尾写明「玩家整理 · 非官方网站」与版权归属。
- **网站画面：** 全部来自真实截图（`capture.cjs`），叠加的线条与「今天」线按截图时记录的元素坐标对齐，不画假界面。
- **素材限制：** 不使用游戏配乐和实机画面。
