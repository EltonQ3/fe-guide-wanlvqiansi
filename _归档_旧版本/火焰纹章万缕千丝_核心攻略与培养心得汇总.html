二、开局决策：难度、模式与主角路线选择

三语站的建议高度一致，可直接作为开局共识。

2.1 难度与模式

项目 推荐 说明
难度 普通（新手）／困难（老手） 困难难度可在「方尖塔大厅」随时下调；但一旦下调，本章进行中无法回调。（AlGest）
模式 轻松（新手）／经典（硬核） 经典模式下伙伴阵亡不会复活；但当章内可用「章重来」回到开头挽回。（AlGest 不可挽回要素）

2.2 四主角路线推荐顺序（三语站共识）

中文站与日文站给出的顺序完全一致——凯伊 → 赛奥朵拉 → 迪托利希 → 蕾达（由简至难）。

顺序 主角 推荐理由 适合人群

三、核心系统机制与心得

3.1 时间与「自由行动」——最容易被误解的机制

核心结论：时钟本身毫无意义，只有「回合数」重要。

  • 每天分为 4 个 6 小时时段（0:00–5:59 / 6:00–11:59 / 12:00–17:59 / 18:00–23:59），每个时段 = 1 回合，4 回合 = 1 天。
  • 时间不会实时流逝——只要你没有执行消耗回合的行动，时钟会自动停住（会停在 5:59 / 11:59 / 17:59 / 23:59）。所以不用担心「浪费时间」。
  • 放置时时间也会走，长时间挂机请先打开菜单。（RPG Site、AlGest）

3.2 每周固定行动（不消耗回合，但每周限一次）

三语站一致建议：统一在「星期日」做，因为周日效果好。

行动 效果 周日加成
用餐（宿屋） 提升同席 3 人的支援值；恢复 HP、魔法次数、干劲 花费减半
训练（斗技场） 提升技能 EXP（最有价值的周常行动） —
奉仕（神殿） 提升加护等级与支援值；获得「神の加護」 贡献度获得量增加
喂食白鸦 提升任意角色与主角 Eshmel 的支援（第三部才生效） 仅周日
送礼 提升想挖角角色的支援值 —
马厩喂食 仅凯伊篇可用 —

实践建议：自由行动期间外出探索达格扎大陆，但每周至少回一次达格席翁完成周常，然后再出发。（AlGest、RPG Site）

3.3 「先见之助言」——自由行动的决策罗盘

从「冒险手帐」可查看先见之助言，他会直接告诉下一场主战所需的准备：

项目 对应准备
推荐 Lv. 去遭遇战或地牢练级
推荐武器 Rank 武器店购买 / 万达鲁商会兑换
推荐兵种 资格考试转职 / 挖角新同伴
推荐道具 购买

自由行动不知道做什么时，打开「冒险の手引き」执行推荐度 3 的内容。宿屋的「おまかせ稼ぎ」（自动活动）主要用于调整时间——比如快接近周日时用它快进。（AlGest）

3.4 支援等级系统——本作最值得优先投入的长期投资

关键机制：支援等级是「全局数值」（Global Value）。

在任意一条路线上提升两名角色之间的支援，该等级会保留并同步反映到其他所有路线，且永远不会下降——即使重开章节也不会掉。这意味着：

  • 你在凯伊篇刷的蕾达 × 其他角色的支援，会让蕾达篇的招募变得更容易。
  • 跨路线重复收益：这是本作性价比最高的长期投资。

提升支援的三种方式（日文站归纳）：

方式 说明
邀请用餐 宿屋内选择用餐，可同时提升同席 3 人支援；同时恢复 HP 与魔法次数，务必每次都用
赠送礼物 只有送对方喜欢的物品才会提升支援值；主要用于尚未入队、想挖角的角色
联手攻击（连携） 地牢等战斗中发动联手攻击可提升参战同伴支援值

支援等级的效果：战斗中相邻的同伴会获得能力加成；高等级可解锁特殊事件（可在宿屋「支援会话」中回看）。

英文站重要提醒： - A 级是上限，本作没有 S 级支援、没有结婚系统；恋爱元素只存在于角色剧本写作中，不是系统机制。 - 不要过度依赖送礼——主要手段应是宿屋「用餐」：可每周多次、可同时提升多组支援、还能提升非主角之间的支援，甚至可邀请不可招募的角色（部分角色有支援对话）。 （RPG Site 支援攻略、AlGest）

3.5 【重点技巧】支援等级速刷法（零成本）

RPG Site 给出的方法，利用「支援全局化 + 不下降 + 章节重开」三个特性叠加：

  1. 重开一个已通关的章节；
  2. 在宿屋为想要提升支援的角色组合举办多轮用餐；
  3. 用宿屋的「自动活动」推进到下一周，继续用餐；
  4. 重复直到该章主战前的回合耗尽；
  5. 基地菜单 → 系统 → 重开章节（Restart Chapter），回到步骤 1。

要点： - 过程中不消耗任何金钱和道具（只是反复读档），理论上甚至不需要中途存档，只要最后存一次。 - 建议选择较长的章节（作者用蕾达篇第 9 章示范），重开前能办更多次用餐。 - 开始前最好已在上一章给所有角色送过礼，否则每次重置都要重新送礼解锁用餐功能。 - 注意部分章节中特定角色群（凯伊、迪托利希、赛奥朵拉、塔利穆恩、阿纳托莉娅的队伍）会不在达格席翁，需换到他们在场的章节。

中文站 18183 已转载编译该攻略。（RPG Site、18183 中文版）

3.6 名声（Renown）与名声等级

  • 名声达到一定数值会提升名声 Lv.，解锁各类要素与新同伴的挖角资格。
  • 主要来源：完成支线任务（Subquest）。自由行动开放后，把所有可接的支线全部接下，并在期限内完成并报告。
  • 其他来源：完成主线、外传、部分事件；与神「会面/拝謁」时也可提升。
  • 注意：迪托利希篇与蕾达篇名声提升明显更难，需要更严格的日程规划。（AlGest、RPG Site 招募攻略）

3.7 战斗系统与计算式（日文站硬核数据）

基础规则： - 武器克制倍率：无特攻 = 等倍；有效 = 武器威力 2 倍；特攻 = 武器威力 3 倍。 - 暴击：伤害 3 倍。 - 追击条件：攻速差 ≥ 4 即可追击（普攻两次）。 - 所有小数向下取整。

核心公式（AlGest 整理）：

项目 公式
物理攻击 力 + 武器威力×特效补正 + 战技补正 + 技能 + 其他补正
魔法攻击 魔力 + 魔法威力 + 战技补正 + 技能 + 其他补正
物理防御 守备 + 装备守备 + 地形 + 其他补正
魔法防御 魔防 + 装备魔防 + 地形 + 其他补正
必杀 (技 + 幸运) ÷ 2 + 武器/魔法必杀 + 技能 + 其他补正
命中 技 + 武器命中 + 战技补正 + 装备命中 + 技能 + 神の加護 + 其他
攻速 速度 −（装备总重量 − 体格），最低为 0
回避 攻速 + 技能 + 地形 + 神の加護 + 其他
必杀回避 幸运 + 技能 + 神の加護 + 其他
物理伤害 (物理攻击 − 物理防御) × 必杀补正 × 技能 × 神の加護
攻击命中率 命中 − 回避
必杀发生率 必杀 − 必杀回避

实战要点：英文站特别强调「本作基本不是回避环境」，因此坦克型角色非常吃香（日文站同样指出这一点）。这与前作以回避为核心的 Meta 有明显差异。（AlGest 战斗计算式、Game8）

关键战斗技巧（Game8）： - 按 ZL 可显示全部敌人的攻击范围（红色高亮），用于卡位与保护脆皮。 - 武器有有效（×2）与有效+（×3）两级：枪对骑兵 ×2、弓对飞行 ×3。 - 攻击速度（AS）= 速度 − 装备重量影响，比对手高 4 以上才能追击——布阵前务必核对 AS、Prt、Rsl。 - 战技（Combat Art）消耗武器耐久，可提升威力/命中/必杀；Blaze Arts 消耗 HP，使用会填充「Blaze Gauge」，充满后降低该单位最大 HP 并清除所有加成。

3.8 Blaze Arts（ブレイズアーツ / 日文「ブレイブアーツ」）——主角专属大招

四位主角各有专属 Blaze Arts，消耗 HP，是改变战局的关键，但使用时机至关重要。

TheGamer 的建议：开启前先确认敌方攻击范围；准备好治疗；尽量把主角移出危险地带；或选在能一举清掉「有能力反击的敌人」时使用。只有当 HP 代价不会引发新的危机时，Blaze Art 才是最有价值的。

各主角 Blaze Arts 特性（三语站汇总）：

主角 Blaze Art 特性 战术定位
凯伊 Cai 范围攻击（本作罕见的 AOE） 高容错主力，机动力极强
迪托利希 Dietrich 强调位移与站位，可快速贴脸；影渡（可无视障碍瞬移） 近战物理爆发、必杀流
赛奥朵拉 Theodora 远程巨岩投掷，攻击范围全游戏最大 顶级肉盾 + 远程支援
蕾达 Leda 范围 Buff 歌曲，可同时强化周边多名同伴 支援核心，需居中站位
伊修玛尔（救世主/真主角） 「破邪闪击」大范围攻击，极为强力 均衡型，起始等级高

蕾达专项建议（TheGamer）：她的歌曲「站位与选曲同等重要」。使用前先查看技能范围，把想强化的单位移入范围，尽量一次覆盖多名能立刻输出的角色。一个实用套路是：把同伴放进敌方攻击范围，再用她提升守备与魔防的技能，从而轻松反杀。

四、角色培养核心心得

4.1 资源分配原则：「少而精优于多而弱」

  • 不要平均培养所有人：每条路线的角色数量都超过你能同步培养的量。先确立5–6 名核心主力用于主战，其余训练机会留给专精角色与未来招募的新人。
  • 核心队伍应覆盖明确分工：耐打的前排、高机动输出、远程火力、可靠的治疗/支援。（TheGamer、今日头条培养思路）

4.2 转职与资格考试

  • 通过资格考试转职（系列传统），需满足技能 Rank 要求 + 消耗「许可证（ライセンス）」。
  • 许可证别只盯着达格席翁的商人——初期物资极度吃紧。其他聚落也售卖许可证，在世界地图上按 ZL 悬停查看库存后再前往。（TheGamer）
  • 日文站强调：确认「先见之助言」中的推荐兵种，据此决定是转职还是挖角新人。

4.3 挖角招募：三项要素 + 附加条件

RPG Site 将招募条件拆解为：

要素 说明
支援等级（nS） 与你的主角之间的支援等级。最佳提升方式：送礼 + 邀请用餐（+ 解锁剧院后邀请看舞台剧）
名声等级（nR） 全局数值，完成主线、支线、外传等提升；也可通过与神「拝谒」提升
附加条件 少量金钱、回答问题、特定道具，或完成 1 个甚至多个支线
外传完成 部分角色必须在完成特定外传后才加入（并非所有路线都能打所有外传）
剧情进度 仅 2 人适用：蕾达篇的法比奥、迪托利希篇的盖茨

同一角色的招募条件在不同路线差异很大。例如洛蕾塔在赛奥朵拉篇只需名声 5，在迪托利希篇则需名声 8。杰斯特需要完成 3 个任务；歌利亚需要 3 个「巨人肉」（沙影要塞必出 1 个，或找世界地图上带巨人图标的遭遇战）；但丁需 8000G。

进阶技巧（RPG Site）：在 Part 1 越晚招募的角色，入队时的等级与装备越好。 如果主力已定，可考虑把一些招募留到后面。Part 2 有专门帮助低等级角色追赶的机制。

⚠️ 跨路线注意：属于其他主角路线的角色，在你切换故事线时可能离开队伍——趁人在时把支援链刷完。

4.4 「救世主」真主角（伊修玛尔 / Eshmel）

  • 玩家可自定义外观与姓名（默认名「伊修玛尔」，男女分别由松冈祯丞、井上麻里奈配音）。
  • 在战斗中使「无名之枪」净化冥界亡者。
  • 喂食白鸦可提升任意角色与其支援，第三部才生效。

4.5 跨路线全局进度：Boon of Salvation 与 Notable Deeds

这是 TheGamer 列为首要建议的长期投资。

  • 完成 Notable Deeds（伟业录 / 成就）可获得 Karma Shards（伟业の欠片 / 业力碎片）。
  • 碎片可在 Shrine of Causality（因果神殿） 兑换 Boons of Salvation（救世の祝福）。
  • Boons 适用于全部四条路线，与路线专属进度不同——一条路线赚的奖励能让下一条路线更轻松。
  • 优先级建议：优先选择「大量经验加成」类 Boon。首条 Part 1 路线约需 20 小时，但后续路线在有加成后会快得多。
  • ⚠️ 不可挽回：救世祝福一旦取得就无法更改。虽然所有效果都是正面的，但如果想优先拿「经验值获取增加」等特定项，请谨慎选择。（TheGamer、AlGest 不可挽回要素）

4.6 【高价值技巧】重复招募角色要「差异化培养」

  • 同一个角色可以在多条 Part 1 路线上入队。
  • 如果你打算在 Part 3 使用该角色，不要让每个版本都练成同一套配置——一个版本练骑马系、另一个走不同武器线，或在不同路线收集不同精通能力。
  • Part 3 的 Merge Causality（合并因果） 系统会把各版本中有用的职业、能力、战技、技能等级和更高属性汇总到最终版本上。（TheGamer）

4.7 各路线专属行动的价值（TheGamer 逐路线建议）

路线 专属行动 建议

六、容易错过的要素与挽回机制（日文站整理）

6.1 不可挽回

项目 说明
救世祝福 一经取得无法更改，选择需谨慎
升级时的属性成长 数值随机，成长趋势受个人成长率与兵种影响；可消耗「天刻的白沙」回溯战斗有限度地挑选结果
第 2 部无法挖角 Part 1 通关进入 Part 2 后，几乎全是战斗部分，挖角等 Part 1 能做的事全部消失——务必在 Part 1 结束前把招募搞定

6.2 可通过「章重来」挽回

基地菜单 → 系统 → 章のやり直し（回到该章开头）：

  • 阵亡的同伴（经典模式）
  • 已过期的任务（注意：若该章开头时尚未触发该任务，重来后需从接取开始）
  • 与同伴对话的选项（部分选项可提升支援值，可借此重选）

6.3 可通过「再降临」挽回

保留剧情进度，重置角色与游戏模式（需先在方尖塔存档，且需重玩序章起见的部分）：

  • 主角姓名与外观
  • 难度与模式

七、角色强度与培养方向

⚠️ 重要前提：请谨慎看待任何「最强角色排名」。英文站（HowToVideoGame）明确指出：发售第二天给出的 Tier List 只是个人档样本，不是数据结论。原因有三：① 成长率随机，同一角色在不同存档差异巨大；② 职业系统自由，角色上限取决于你把他练成什么；③ 支援与角色数据跨路线合并，强度还取决于你练过几条路线。

7.1 万用结论：五位主角必强

凯伊、迪托利希、赛奥朵拉、蕾达、伊修玛尔——这五人强制在队、始终可用、且是仅有的 Blaze Arts 持有者，稳定性最高。这一点三语站无异议。

7.4 真正该投资的三件事（而非追逐排名）

英文站给出了最实用的结论——不要追 Tier List，投资这三项结构性要素：

  1. 个人技能（Personal Ability）——固定且不可转移，是唯一不随存档变化的要素。例：提升周边同伴回避、可在战场直接使用仓库、减轻武器重量、有概率以 1 HP 存活致命一击。
  2. 技能等级（Skill Level）——驱动战技与可装备能力，在斗技场投入的时间会复利，不论你练的是谁。
  3. 支援等级——永不下降、跨路线继承，是全游戏最安全的长期投资。

（HowToVideoGame）
