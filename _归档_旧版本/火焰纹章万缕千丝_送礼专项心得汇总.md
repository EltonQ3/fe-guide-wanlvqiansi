# 《火焰纹章 万缕千丝》送礼（赠り物）专项心得汇总

> 本文为《火焰纹章 万缕千丝 / 万紫千红》（Fire Emblem: Fortune's Weave）**送礼系统**的专项整理，综合日文站（AlGest / GameWith）、中文站（游侠网 / 3DM / 新浪 / 巴哈姆特）、英文站（Polygon / Game8 / Nintendo Insider / VGC / RPG Site）资料。
>
> 彙整時間：2026-09-19（发售第 3 天）。各站表格仍在施工更新，礼物品项与喜好可能陆续补完。

## 一、一句话结论

> **送礼的核心作用是「解锁用餐资格」和「补足支援差」，不是主力刷支援手段。**
>
> 送对礼物（对方喜欢的）获得的支援量 ≈ 请对方吃一顿他喜欢的饭。但由于**赠礼每周每人只能一次**，而用餐**每周可办 3 次 × 3 人**，因此英文站（RPG Site）明确建议：**不要把送礼当主要手段**，主力应是宿屋用餐。

## 二、送礼的机制规则（三语站一致）

| 规则 | 内容 |
|---|---|
| **每周限一次** | 赠礼是**每周行动**，同一角色一周只能送一件（Polygon / VGC） |
| **每周日重置** | 每周从**星期日**开始（VGC） |
| **地点限制** | 只有在角色**人在达格席翁（Dagsion）**时才能送。可从地图菜单的**角色页签**查看谁在场、当前支援等级，并**直接快速传送**过去（VGC） |
| **首次送礼 = 解锁用餐** | **送出第一件礼物后，才能邀请该角色参加宿屋用餐**（Nintendo Insider / VGC）——这是送礼最关键的机制作用 |
| **招募前置** | 每个角色**至少需送出 1 件礼物**，才可能成为可招募对象（Nintendo Insider） |
| **支援量分级** | 见下表 |

### 支援增加量分级（Polygon 实测）

| 反应 | 支援增幅 | 说明 |
|---|---|---|
| 不喜欢 | **无支援增加** | — |
| 有点喜欢 | 小幅增加 | — |
| 喜欢 | 中等增加 | — |
| **非常喜欢** | **大幅增加** | 约等于请吃一顿他喜欢的饭 |
| **非常喜欢 + 双黄箭头** | **双倍点数** | 仅限「最爱物品」 |

### 礼物稀有度（Polygon）

| 稀有度 | 图标特征 |
|---|---|
| **普通** | 深蓝绿色图标 |
| **罕见** | 颜色更浅，**右下角有符号** |
| **稀有** | 更浅，**左上角有小闪光** |

> **注意**：部分角色**只接受罕见或稀有的物品**，无论类别（例：卡塔尼娅偏好「任意稀有物品」）。

### 获取渠道

| 渠道 | 说明 |
|---|---|
| **各城镇市集商人** | 世界地图上各城镇/城市均有，**达格席翁商店街尽头**也有一处 |

## 三、核心技巧（按重要度排序）

### 技巧 1：用「物品描述」反查角色 —— 本作的关键机制

> 本作对「谁喜欢什么」**刻意保持模糊**。礼物本身的描述会写明「主要为喜爱书籍者所享受」之类，**玩家需要自己反查匹配的角色**。（Nintendo Insider）

**举例**：一件描述为「喜爱书籍/阅读者」的礼物，可选对象包括——
**奥罗拉、本迪茨、贝尔特兰、菲亚娜、露迪娅、奈丁、奥尔赫尔、西洛可、蒂亚拉、乌修拉**

**辅助判断线索（VGC）**：
- **成年人**普遍喜欢发酵饮料，**儿童不喜欢**
- 从**外观**可推测——例如看起来讲究时尚的角色会喜欢时尚类
- 查看角色信息会**直接透露部分喜好**

### 技巧 2：别死磕「最爱」，退而求其次完全可以

> Polygon 原话大意：如果某一周甚至整章都没有对方「非常喜欢」的东西，**给个他「勉强能接受」的也完全没问题**——第一部结束前有充足时间刷支援，不必焦虑。

### 技巧 3：餐桌才是主力，送礼用来补齐

VGC 给出的最优组合：

1. **每周 3 顿用餐**（宿屋上限 3 次 × 3 人）
2. 如果目标是招募：**每顿饭都必须包含「你的主角 + 两个想招募的对象」**
3. **先送一次礼**给 Guest，才能邀请他入席
4. **如果某位 Guest 不喜欢当天的菜色，就换成另一位喜欢该菜色的招募目标**
5. **三人越都爱吃，支援涨得越多**

> 这被 VGC 称为「升高支援等级最有效率的方式之一」。送礼在这里的角色是**补足那些没上餐桌的人**。

### 技巧 4：剧院（Theatre）—— 被忽略的第三渠道

剧院开放后可看演出甚至参演（VGC）：

- **参演**：只能从**已招募**的角色中选择
- **观演**：可包含**主角 + 一位 Guest**
- **只要两人真的喜欢该场演出**，就能获得**可观的支援提升**

### 技巧 5：战斗与连携也能刷

| 方式 | 说明 |
|---|---|
| **相邻战斗** | 让想提升支援的两名角色**相邻站位**并攻击敌人结束回合，每次获得小额支援加成；**每场战斗的每个回合都能刷** |
| **连携攻击（Link Attack）** | 地牢战等场景发动连携攻击，同样提升两人支援 |

### 技巧 6：注意角色在场情况

某些章节中特定角色群**不在达格席翁**——凯伊、迪托利希、赛奥朵拉、塔利穆恩、阿纳托莉娅的队伍会缺席。想给这些人送礼或办餐会，**需换到他们在场的章节**。（RPG Site）

## 五、实战行动清单（可直接照做）

**每周固定流程：**

1. **星期日**一到，先回达格席翁（周日用餐花费减半，奉仕贡献度增加）
2. 打开地图 → 角色页签，**确认本周有谁在场**
3. 给**尚未送过礼的招募目标各送 1 件**（解锁用餐资格是首要目的）
4. **办 3 顿饭**，每顿都安排「主角 + 2 名招募目标」，尽量选三人都爱吃的菜色
5. 若目标角色不在场，**换到他在场的章节**再处理
6. 顺路去**剧院**看一场演出（主角 + 1 名 Guest）

**资源分配：**

- **尽早点出「赠礼折扣」救世祝福**——礼物很贵，这是长期省钱关键
- 送礼是**补差手段**，把最好的礼物留给**当前最急需招募的角色**
- 没有「最爱」时，直接给「能接受」的，不必等

**优先级判断：**

> 如果目标是**尽快招募强力角色**，优先顺序应为：
> **① 每周 3 顿精准用餐 ＞ ② 每周 1 次送礼（解锁+补差） ＞ ③ 剧院观演 ＞ ④ 战斗相邻刷支援**
