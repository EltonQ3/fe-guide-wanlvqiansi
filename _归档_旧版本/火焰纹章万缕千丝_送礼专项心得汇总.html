《火焰纹章 万缕千丝》送礼（赠り物）专项心得汇总

本文为《火焰纹章 万缕千丝 / 万紫千红》（Fire Emblem: Fortune's Weave）送礼系统的专项整理，综合日文站（AlGest / GameWith）、中文站（游侠网 / 3DM / 新浪 / 巴哈姆特）、英文站（Polygon / Game8 / Nintendo Insider / VGC / RPG Site）资料。

彙整時間：2026-09-19（发售第 3 天）。各站表格仍在施工更新，礼物品项与喜好可能陆续补完。

一、一句话结论

送礼的核心作用是「解锁用餐资格」和「补足支援差」，不是主力刷支援手段。

送对礼物（对方喜欢的）获得的支援量 ≈ 请对方吃一顿他喜欢的饭。但由于赠礼每周每人只能一次，而用餐每周可办 3 次 × 3 人，因此英文站（RPG Site）明确建议：不要把送礼当主要手段，主力应是宿屋用餐。

三、核心技巧（按重要度排序）

技巧 1：用「物品描述」反查角色 —— 本作的关键机制

本作对「谁喜欢什么」刻意保持模糊。礼物本身的描述会写明「主要为喜爱书籍者所享受」之类，玩家需要自己反查匹配的角色。（Nintendo Insider）

举例：一件描述为「喜爱书籍/阅读者」的礼物，可选对象包括—— 奥罗拉、本迪茨、贝尔特兰、菲亚娜、露迪娅、奈丁、奥尔赫尔、西洛可、蒂亚拉、乌修拉

辅助判断线索（VGC）： - 成年人普遍喜欢发酵饮料，儿童不喜欢 - 从外观可推测——例如看起来讲究时尚的角色会喜欢时尚类 - 查看角色信息会直接透露部分喜好

技巧 2：别死磕「最爱」，退而求其次完全可以

Polygon 原话大意：如果某一周甚至整章都没有对方「非常喜欢」的东西，给个他「勉强能接受」的也完全没问题——第一部结束前有充足时间刷支援，不必焦虑。

技巧 3：餐桌才是主力，送礼用来补齐

VGC 给出的最优组合：

  1. 每周 3 顿用餐（宿屋上限 3 次 × 3 人）
  2. 如果目标是招募：每顿饭都必须包含「你的主角 + 两个想招募的对象」
  3. 先送一次礼给 Guest，才能邀请他入席
  4. 如果某位 Guest 不喜欢当天的菜色，就换成另一位喜欢该菜色的招募目标
  5. 三人越都爱吃，支援涨得越多

这被 VGC 称为「升高支援等级最有效率的方式之一」。送礼在这里的角色是补足那些没上餐桌的人。

技巧 4：剧院（Theatre）—— 被忽略的第三渠道

剧院开放后可看演出甚至参演（VGC）：

  • 参演：只能从已招募的角色中选择
  • 观演：可包含主角 + 一位 Guest
  • 只要两人真的喜欢该场演出，就能获得可观的支援提升

技巧 5：战斗与连携也能刷

方式 说明
相邻战斗 让想提升支援的两名角色相邻站位并攻击敌人结束回合，每次获得小额支援加成；每场战斗的每个回合都能刷
连携攻击（Link Attack） 地牢战等场景发动连携攻击，同样提升两人支援

技巧 6：注意角色在场情况

某些章节中特定角色群不在达格席翁——凯伊、迪托利希、赛奥朵拉、塔利穆恩、阿纳托莉娅的队伍会缺席。想给这些人送礼或办餐会，需换到他们在场的章节。（RPG Site）

五、实战行动清单（可直接照做）

每周固定流程：

  1. 星期日一到，先回达格席翁（周日用餐花费减半，奉仕贡献度增加）
  2. 打开地图 → 角色页签，确认本周有谁在场
  3. 给尚未送过礼的招募目标各送 1 件（解锁用餐资格是首要目的）
  4. 办 3 顿饭，每顿都安排「主角 + 2 名招募目标」，尽量选三人都爱吃的菜色
  5. 若目标角色不在场，换到他在场的章节再处理
  6. 顺路去剧院看一场演出（主角 + 1 名 Guest）

资源分配：

  • 尽早点出「赠礼折扣」救世祝福——礼物很贵，这是长期省钱关键
  • 送礼是补差手段，把最好的礼物留给当前最急需招募的角色
  • 没有「最爱」时，直接给「能接受」的，不必等

优先级判断：

如果目标是尽快招募强力角色，优先顺序应为： ① 每周 3 顿精准用餐 ＞ ② 每周 1 次送礼（解锁+补差） ＞ ③ 剧院观演 ＞ ④ 战斗相邻刷支援
